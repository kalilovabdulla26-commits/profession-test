# Тест на профессию

Готовый статический сайт для публикации через GitHub Pages.

## Файлы
- `index.html` — HTML, вопросы и логика теста
- `style.css` — адаптивные стили сайта

## Публикация на GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` и `style.css` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет ссылку на сайт.

Важно: оба файла должны лежать в одной папке (в корне репозитория), чтобы подключение `style.css` работало.
